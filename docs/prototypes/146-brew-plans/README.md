# PROTOTYPE：#146 沖煮計劃表 ②：三個 375px 版本

> 拋棄式 prototype，放在 `claude/brew-plans-ui-6a0e22` 分支，**不要合進 main**。作者選定以後，
> 正式實作會依選定版本重寫；這個分支留著當原始資料。

## 怎麼開

```bash
npm run dev   # → http://localhost:8787/#/proto-plans/list?variant=A
```

- 路由 `#/proto-plans/<screen>?variant=A|B|C`，screen 是 `me` / `list` / `plan/<id>` / `new` / `copy/<id>`。
- 底部黑色膠囊用來切換版本（也可以按 ← →），右邊的選單可以跳到其他畫面。換版本時，編輯中的內容會保留。
- 資料都在記憶體裡，重新整理就回到樣本；儲存會 `console.log` 送給 API 的內容（`steps` 只有累計 `to_g`）。
- 只在 `localhost` / `127.0.0.1` 開；其他 host 一律顯示「找不到頁面」。
- 程式：`public/proto-plans.prototype.{js,css}`，`app.js` 加一行路由、`index.html` 引入這兩個檔。

內建手沖法取自 #143 的表格（⚠ 數值是 AI 暫定）；「我的計劃」三筆、帳號 `proto@example.com` 都是假資料。

## 三個版本

| | **A 表格** | **B 卡片** | **C 時間軸** |
|---|---|---|---|
| `#/me` 入口 | 和「我的數據」同款的第二張入口卡（就是 issue 寫的做法） | 「我的數據」和「沖煮計劃」合成一張「工具」卡，加圖示與副標（幾個我的、幾個內建） | 入口卡直接列出最近 2 個計劃＋「全部 ›」 |
| 清單 | 密集的列表，一列一個計劃，右邊是 `粉/水 g`、`1:N · 斷水`；標籤 chip 換行排列 | 每個計劃一張卡，左邊大字粉水比；標籤是可橫向捲動的 pill；「新增」是虛線大按鈕 | 每個計劃一條迷你時間軸（注水是點、點的大小代表那一注的水量，等待是虛線）；標籤篩選用下拉選單 |
| 編輯頁 版面 | 一頁表單；總水量 / 粉水比 / 斷水是 sticky 的頂部條 | 一步一張卡，輸入框大；總水量 / 粉水比 / 斷水＋儲存固定在底部 dock | 頂部深色 hero：名稱＋三個大數字；步驟是直式時間軸；說明 / 器材 / 粉量收在下方的 `<details>` |
| 步驟列 | 表格欄位：時間｜水量｜另一個值｜×，一列放得下 | 卡片標題「第 n 注」＋大的時間 / 水量輸入，另一個值在輸入框下方 | 時間軸節點：時間｜水量 g｜另一個值｜×；等待是兩注之間的虛線段 |
| 累計 / 本次 | 步驟卡右上的小分段切換；欄位標題跟著換 | 全寬的大分段切換，下方一行說明目前輸入的是什麼 | 時間軸標題旁的小分段切換 |
| 進階 | 步驟最後一行的「進階 ⌄」連結 | 步驟標題旁的 switch「進階（水溫・備註）」 | 「進階」按鈕（會亮） |
| 內建詳細頁 | 一張 key-value 卡＋表格式步驟列 | hero 卡（六格大數字）＋每步一張卡；「複製成我的」固定在底部 | hero 加迷你時間軸；步驟是唯讀的時間軸 |
| 優點 | 最省空間，一次看得到最多步驟；最接近現有表單的風格 | 最好按，數字最大，沖煮時看得清楚；儲存一直看得到 | 最能看出食譜的「形狀」（節奏、等待、大注 / 小注），清單一眼就能比較 |
| 代價 | 輸入框小（約 64–74px）；版面比較「表單」 | 最長：5 注的 4:6 在「進階」打開時約 2000px 高，要捲很久 | 名稱藏在 hero 裡、其他基本欄位收起來，新增時容易漏填；迷你時間軸要多寫程式 |

三個版本都有：說明（一般顯示）、注水 / 等待步驟列、＋注水 / ＋等待（30 步時停用）、第一注的「悶蒸」、
累計 / 本次切換（同時換算顯示和輸入，切換時整批換算）、進階裡的每注水溫（placeholder 是整體水溫）
和每步備註、即時的總水量 / 粉水比 / 斷水次數、內建唯讀頁的「+60 g · 累計 120 g」與「複製成我的」、
刪除前的確認視窗。

## 已在瀏覽器驗證（375px）

- 4:6 例子：「本次」60 × 5 ↔「累計」60 / 120 / 180 / 240 / 300；總水量 300 g、粉量 20 → 1:15、斷水 4。
- 「本次」把第 2 注改成 80 → 切到「累計」是 60 / 140 / 200 / 260 / 320；
  「累計」把第 2 注改成 140 → 切到「本次」是 60 / 80 / 40 / 60 / 60。
- 第 3 注空白時來回切換，其他注不變、空白仍是空白；累計沒有遞增時標紅，切到「本次」顯示負數（-20）。
- 新增：20 g、0:00→60（悶蒸）、0:45→120、1:30→180 → 180 g、1:9、斷水 2；加一個等待步驟後斷水還是 2；儲存後回到清單、排在最前面。
- 複製 Hoffmann 2 杯 → 名稱「James Hoffmann Ultimate V60（2 杯）（複製）」、5 步、500 g / 1:16.7 / 斷水 2。
- 標籤篩選、頁面上沒有缺 `type="button"` 的按鈕、所有畫面 `scrollWidth` = 375（沒有水平捲軸）。
