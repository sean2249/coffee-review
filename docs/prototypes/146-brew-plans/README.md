## 怎麼開

```bash
npm run dev   # → http://localhost:8787/#/proto-plans/list?variant=C1
```

- 路由 `#/proto-plans/<screen>?variant=C1|C2`，screen 是 `me` / `list` / `plan/<id>` / `new` / `copy/<id>`。
- 底部黑色膠囊用來切換版本（也可以按 ← →），右邊的選單可以跳到其他畫面。換版本時，編輯中的內容會保留。
- 資料都在記憶體裡，重新整理就回到樣本；儲存會 `console.log` 送給 API 的內容（`steps` 只有累計 `to_g`）。
- 只在 `localhost` / `127.0.0.1` 開；其他 host 一律顯示「找不到頁面」。
- 程式：`public/proto-plans.prototype.{js,css}`，`app.js` 加一行路由、`index.html` 引入這兩個檔。

內建手沖法取自 #143 的表格（⚠ 數值是 AI 暫定）；「我的計劃」三筆、帳號 `proto@example.com` 都是假資料。

**線條上的 signal（清單、編輯、詳細頁共用一套）：**
- **注水圖**（摘要卡和清單每一列）：橫軸是時間，每注是一根直條，**高度 = 這注的水量**；悶蒸是空心條；等待是帶斜線的帶狀。編輯時會即時更新，所以自己的計劃上方也有一條。
- **時間軸節點**：注水是實心點，**點的大小 = 這注的水量**，下面一條**水量條**（同一計劃中最大的那注 = 滿）；等待是沙漏方塊＋虛線＋米色底，右邊顯示「等 45 秒」（= 這一步減前一步的時間）。
- **顏色**：注水是主色（墨綠）、等待是褐色、水溫是磚紅，三種意思不混用。

**C1 和 C2 只差一件事：**
- **C1 等距**：每一步一樣高，最省空間。
- **C2 時間比例**：步驟之間的空白與相隔秒數成比例（上限 72px），長等待（例：Hoffmann 1:15 → 3:30）一眼看得出來；代價是畫面比較長，編輯時也會跟著跳動。
